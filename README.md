# SE4X-excel

__Excel files for the Space Empires 4X board game__

The project contains Excel files to be used as digital production sheets for different versions of SE4X, which differ in terms of CP costs, unit types and technologies for the various extensions:

    Basic Classic. Production sheet for the base game (basic rules and advanced rules) without extensions.

    Basic 1.3. Production sheet for revision 1.3 of the base game (basic rules and advanced rules) without extensions. 

    AGT No facilities. Production sheet for the "All Good Things" revision of the base game (basic rules and advanced rules) including all extensions. 

## Instructions
- Make a copy of the Excel file you want to use.
- Each Excel file consist of two sheets, "Production" and "Ship Technology".
- In economy phase, carry out all calculations and notes on the "Production" sheet.
- Be aware of the increasing and decreasing the maintenance costs by entering the gains and losses of hull points.  
- When acquiring a technology, mark the technology using the "Current" drop down box on the "Production" sheet.
- Based on the acquired technologies, on the "Ship Technology" sheet, a green bar next to the unit (group) marks if a unit type is available.  
- When acquiring a unit (group), mark both check boxes next to the group on the "Ship Technology" sheet.
    - The left check box marks if a group is on the board. When checked, the group will be marked in green.
    - The right check box marks if a group receives technology upgrades. When checked, the group specs will be updated according to the acquired technologies on the "Production" sheet, and limited by the maximum specs for the various unit types.
        - When playing with "Automatic Upgrades" (9.11.4) [^1], leave the right check box marked as long as the group is on the board; the specs will be updated automatically.
        - When playing with technology upgrades at shipyards, unmark the right check box after the initial update of the specs. When upgrading a group at a shipyard, briefly mark and unmark the right check box to update the specs.
